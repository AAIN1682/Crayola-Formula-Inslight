# Crayola Product Screening

Monorepo layout for Formula Insight and future backend services.

| Folder | Description |
| --- | --- |
| [`frontend/`](frontend/) | Formula Insight React app (Vite, TypeScript, Tailwind). See [frontend/README.md](frontend/README.md). |
| [`backend/`](backend/) | Reserved for backend code (not implemented yet). |

## Quick start (frontend)

```bash
cd frontend
npm install
npm run dev
```
